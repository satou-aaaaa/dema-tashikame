# デマたしかめ

SNSの投稿を、広める前に「出どころ」「日付」「写真」「公式・報道」で確かめ、「広める」「広めない」「広めずに待つ」を決める1日5問の学習ゲーム。災害のときに回りやすいデマに強くなる練習です。

- 遊ぶ: https://satou-aaaaa.github.io/dema-tashikame/
- 今日の5問（やさしい2・ふつう2・むずかしい1）はだれでも同じで1日1回。上級（むずかしい3問・ヒントなし）、練習（何度でも）、とことん（何問見抜けるか・まちがえても続く）、見た手口が集まる「たしかめ帳」があります。
- 出てくる町・人・アカウント・投稿は、すべて作り話です。実在の人・投稿は使っていません。
- 見やすさの設定（読みやすい文字・色の見分け・動きを減らす・読み上げ）と、機種を変えるときの「引き継ぎ」があります。

## 確かめ方の出どころ

- 総務省「上手にネットと付き合おう！」偽・誤情報：発信元・書かれた時期・一次情報を確かめ、ほかの情報と比べる。正しいか分からないときは拡散しない（<https://www.soumu.go.jp/use_the_internet_wisely/special/fakenews/>）
- 総務省 検討会資料（2024年4月）：災害時は善意の拡散が多い、別の場所の画像・動画や AI で作った画像の例、公式の発表による訂正（<https://www.soumu.go.jp/main_content/000942565.pdf>）
- 総務省 令和5年版 情報通信白書：ファクトチェックを知っている人は日本で46.5%（<https://www.soumu.go.jp/johotsusintokei/whitepaper/ja/r05/html/nd123400.html>）

本当の災害のときは、市町村・気象庁・消防などの公式の発表を見てください。

## 記録と通信

記録は遊ぶ人のブラウザにだけ残り、ゲームから自動で外へ送ることはありません。例外は2つ：文字（Google Fonts）を読み込むとき、まだ端末に保存が無ければ Google に IP アドレスが届きます。「Xで投稿」「LINEで送る」「結果をシェア」を押したときだけ、結果の文が選んだ先に渡ります（投稿の中身と答えは入りません）。
